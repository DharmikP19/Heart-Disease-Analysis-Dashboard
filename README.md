🫀 Heart Disease Analysis Dashboard (Power BI)
📌 Overview
This project presents a Heart Disease Analysis Dashboard built using Power BI to analyze patient health data and identify patterns related to heart disease risk.
The dashboard focuses on comparing clinical health indicators across patients and highlighting differences by gender and medical attributes to support data-driven health anal ysis.

📂 Dataset
The dataset consists of patient-level medical and health measurements related to heart disease, including:
🧑 Age
🩸 Cholesterol levels
💓 Resting blood pressure
📈 Maximum heart rate
🩺 Anemia indicator
🚻 Gender

❤️ Heart disease presence
The data is analyzed directly within Power BI for visualization and insight generation.

🛠 Tools & Technologies

📊 Power BI Desktop
🔄 Power Query – Data cleaning and transformation
🧮 DAX – Aggregated measures and KPIs
